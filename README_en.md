## 1. Positioning

Deploys a local agent: writing and running code (mainly Python), running analysis,
writing, translation, general knowledge Q&A, web search, local knowledge-base retrieval,
and file read/write.

## 2. Architecture

- Started via `main.py`, which assembles: `core/llm.py` (LLM) + `tools/local_tools.py`
  (local tools) + `skills/skill_loader.py` (skills) + `tools/mcp_setup.py` (MCP filesystem
  tools) + `tools/rollback.py` / `tools/git_tool.py` (rollback/Git)
- All tools are mounted on the `SingleAgent` in `agent.py` (`create_react_agent`); the
  system prompt = tool usage guidelines + skill index; conversation history keeps the last
  20 messages, ReAct ≤ 20 steps
- Tools fall into two categories:
  - **Read-only / no side effects**: run directly (e.g. calculator, read_file,
    search_local_knowledge_base)
  - **Write / execute**: go through `confirm.py` for human confirmation first; once
    approved, `rollback.py` auto-backs-up before executing (write_file, python_exec,
    edit_file, move_file, mutating git subcommands, etc.)
- Each turn's execution trace (content excluded) is written to a session log generated by
  `core/logger.py`

**No supervisor, no workers** — one LLM + one prompt + a pile of tools.

> Always start with `python main.py` from inside the `SINGLE_AGENT/` directory; modules
> use absolute imports across sub-packages (e.g. `from tools.confirm import confirm_action`).
> Sync the whole folder when changing code.

## 4. Tool Set

- **Local tools**: write_file, python_exec (preferred), run_python_script, calculator,
  current_time, baidu_search, search_local_knowledge_base
- **Skill tool**: `load_skill(name)` loads a skill's full instructions on demand
- **Rollback tools**: `list_backups` / `rollback(id)`
- **Git tool**: `git_command`, restricted subcommand allowlist, mutating ones require
  review; comes with built-in merge-conflict checks, an automatic safety tag before
  pull/merge, and rejects `--allow-unrelated-histories`
- **MCP filesystem tools** (launched via npx): read/list/search/get_file_info etc. are
  read-only, plus create_directory/edit_file/move_file

## 5. Agent Skills

- `skills/*.md`, frontmatter contains `name` + `description`; the index stays resident in
  the prompt at startup, the body is injected on demand via `load_skill`
- Adding a new skill just means adding one `.md` file — no code changes needed,
  `skill_loader.py` scans automatically

## 6. Safety Mechanisms for Write Operations

- **Human review** (`confirm.py`): write/edit/delete tools print a summary before running
  and block waiting for y/n; refusing skips execution
- **Auto rollback** (`rollback.py`): once approved, the old state is backed up first
  (write/edit keep the old content, move records the original path, mkdir is recorded as
  "newly created"), stored in `backups/manifest.json` + `<id>.bak`; `rollback(id)` reverts
  it. Retention policy: ≤5 per path, ≤200 total, oldest evicted first
- Not covered: `python_exec`/`run_python_script` (arbitrary code is uncontrollable); Git
  has its own independent safety net

## 7. Self-Built RAG Local Knowledge Base

`texts/*.txt` chunked by paragraph, three retrieval modes (default: hybrid):
- **Dense**: strong at matching semantically similar/synonymous phrasing, depends on the
  embedding model, less sensitive to proper nouns
- **BM25**: accurate and fast on keyword/proper-noun matching, no semantic understanding
- **Hybrid**: RRF-fuses both, widest coverage, the default recommendation; when the
  knowledge base is small and queries are mostly keyword-style, BM25 alone can be used

## 8. LLM Backends

Can load a local model or use an external model via API. Limited by hardware, locally only
models under 27B run reasonably — e.g. qwen2.5-7b runs smoothly, while qwen3.6-27b slows
down noticeably.

## 9. Conversation Memory and Logging

History keeps the last 20 messages (10 turns); a context-size warning is printed past
600,000 characters.

## 10. Hard Limits

ReAct ≤ 20 steps (recursion limit 44); MCP single read ≤ 40,000 characters auto-truncated;
warning at ≈600,000 characters of input; rollback records ≤5 per path / ≤200 total.

## 11. Running It

```bash
cd SINGLE_AGENT && python main.py
```
Type `new` to start a new conversation, `exit` to quit.
